# Implementation plan

1. Capture the immutable current facts and global prohibited actions in a machine-readable index.
2. Draft provider-neutral decision documents for productive IdP, real corpus, Cloud SQL lifecycle and production controls.
3. Define a strict JSON Schema for separate human decision receipts.
4. Require explicit authority roles, bounded scope, approved actions, constraints and evidence references.
5. Implement a deterministic validator for packet state, document headings, cross-references, known facts, prohibited actions and common secret patterns.
6. Add named EVAL, CI wiring, ADR, risk review, traceability and independent review.
7. Run all repository validation, regression, dependency and secret/PII gates.
8. Persist the exact functional SHA and blockers without executing any gated action.
