Pregunta sobre documentos municipales. Revisa las fuentes.

Escribe una pregunta y consulta la información disponible en documentos municipales. Cada respuesta muestra las fuentes que la respaldan. Si no hay información suficiente, el sistema te lo indica.

03

La integración no debe exponer secretos

En sitios externos, el widget se conecta a una dirección HTTPS configurada sin incluir credenciales sensibles en el navegador.

Para sitios institucionales

Añade el asistente a tu sitio.

Puedes insertar el widget y conectarlo a una API HTTPS. La configuración pública sólo debe indicar la dirección del servicio; no incluyas secretos ni credenciales en el navegador.

Si no configuras una API: el widget externo queda deshabilitado y no muestra respuestas de ejemplo.
